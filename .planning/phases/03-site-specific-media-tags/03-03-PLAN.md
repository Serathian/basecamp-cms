Step 4: Populate media tables. Attribution by inspecting FK columns on consumer tables:
- `jr_media`: records referenced by `jr_posts.cover_image_id`

- `rotr_media`: records referenced by `rotr_posts.cover_image_id`

- A record referenced by multiple sites is unusual but handle by prioritizing in order jr → nitf → rotr (INSERT OR IGNORE pattern using ON CONFLICT DO NOTHING)

```sql
-- NITF media (referenced by nitf_posts)
INSERT INTO nitf_media (id, alt, filename, mime_type, filesize, width, height, focal_x, focal_y, updated_at, created_at)
SELECT m.id, m.alt, m.filename, m.mime_type, m.filesize, m.width, m.height, m.focal_x, m.focal_y, m.updated_at, m.created_at
FROM media m
INNER JOIN nitf_posts p ON p.cover_image_id = m.id
ON CONFLICT (id) DO NOTHING

-- ROTR media
INSERT INTO rotr_media (...) SELECT ... FROM media m INNER JOIN rotr_posts p ON p.cover_image_id = m.id ON CONFLICT (id) DO NOTHING
```

Simplified and correct approach:
```sql
-- 1. JR-referenced
INSERT INTO jr_media (...) SELECT m.* FROM media m INNER JOIN jr_posts p ON p.cover_image_id = m.id ON CONFLICT (id) DO NOTHING
-- 2. NITF-referenced
INSERT INTO nitf_media (...) SELECT m.* FROM media m INNER JOIN nitf_posts p ON p.cover_image_id = m.id ON CONFLICT (id) DO NOTHING
-- 3. ROTR-referenced
INSERT INTO rotr_media (...) SELECT m.* FROM media m INNER JOIN rotr_posts p ON p.cover_image_id = m.id ON CONFLICT (id) DO NOTHING
-- 4. Orphans → jr_media
INSERT INTO jr_media (...) SELECT m.* FROM media m
  WHERE NOT EXISTS (SELECT 1 FROM jr_media jm WHERE jm.id = m.id)
    AND NOT EXISTS (SELECT 1 FROM nitf_media nm WHERE nm.id = m.id)
    AND NOT EXISTS (SELECT 1 FROM rotr_media rm WHERE rm.id = m.id)
```

NOTE: The actual columns in `media` may vary. Inspect the real table with information_schema before writing INSERT SELECT. Prefer SELECT with explicit column list to avoid surprises. Also: `jr_media`, `nitf_media`, `rotr_media` SERIAL PKs will have sequences starting at 1 — after INSERT the sequence may conflict with explicit IDs. Use `SELECT setval('jr_media_id_seq', (SELECT MAX(id) FROM jr_media))` after each INSERT to reset sequences.
