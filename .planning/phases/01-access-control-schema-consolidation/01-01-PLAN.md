  <action>
Create `src/collections/users/access/published.ts` with the following implementation:

```typescript
const published = ({ req: { user } }: any) => {
  // Authenticated users see everything (drafts + published)
  if (user) return true

  // Unauthenticated users see only published
  return { status: { equals: 'published' } }
}

export default published
```

This replaces the broken `anyone()` pattern. When `user` is present (authenticated request), return `true` to allow access to all documents. When `user` is undefined (unauthenticated request), return a query constraint that filters to only published documents.

The fix is simple: check user presence FIRST, not after calling `anyone()` which always returns true.
</action>
